# 📦 Sistema de Controle de Estoque

Um sistema simples e intuitivo para gerenciamento e controle de estoque de produtos, desenvolvido com tecnologias web fundamentais (HTML, CSS e JavaScript).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação das páginas e formulários.
- **CSS3:** Estilização, layout e responsividade.
- **JavaScript (ES6+):** Lógica de manipulação do DOM e gestão dos dados do estoque.

---

## 🚀 Como Executar o Projeto

### 📋 Pré-requisitos
Não é necessária a instalação de nenhuma dependência ou servidor pesado. Você só precisa de um navegador web atualizado (Google Chrome, Firefox, Edge, etc.).
